
# Python Banking System

## Project Description
This project is developed using Python and Object-Oriented Programming.
It provides basic banking operations.

## OOP Concepts
- Classes and Objects
- Constructors and Methods
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Main Classes
1. Customer
2. Bank
3. BankAccount
4. Transaction

## Features
- Create bank accounts
- Deposit money
- Withdraw money
- Check account balance
- View transaction history

## Technologies Used
- Python
- Google Colab
- Graphviz
